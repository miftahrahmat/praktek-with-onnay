# Barudak Bageur: Panduan Kerja Claude

@BRAND_KIT.md

## Aturan

- **Semua hasil kerja disimpan di folder `hasil/`.** Ini berlaku untuk desain, caption, naskah, poster, dan dokumen lain. Jangan menyimpan hasil di root repo atau folder lain.
- Ikuti BRAND_KIT.md untuk suara, warna, huruf, format ukuran, serta daftar boleh dan jangan.
- Bagian bertanda ⚠️ di BRAND_KIT.md belum dikonfirmasi. Jangan menulisnya sebagai fakta, dan jangan mengarang angka, nama, atau capaian.
- Folder `reference/` hanya untuk inspirasi. Jangan menyalin elemen merek dari sana.
